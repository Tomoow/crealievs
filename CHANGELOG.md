# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-26

### Added
- Initial release of Crealievs Design System
- **Badge** component - Status indicators and labels with icon support
- **Button** component - Interactive button elements with multiple variants
- **Checkbox** component - Form checkboxes with label and description support
- **FAB** (Floating Action Button) component - Floating action buttons with positioning
- **IconButton** component - Icon-only buttons with tooltip support (plain and rich)
- **RadioButton** components - RadioGroup and RadioOption for mutually exclusive selections
- **Tag** component - Tag/label components with selection and icon support
- **Tooltip** component - Tooltip/popover components (plain and rich variants)
- Design tokens (CSS variables) for colors, spacing, typography, and more
- Full TypeScript support with exported types
- Storybook documentation for all components

### Technical
- Library mode build configuration for npm distribution
- ESM and CommonJS support
- TypeScript declaration files
- CSS bundling for component styles
- Peer dependencies for React 18+ and React 19+
