# OrderCard

Bar order card for staff: **incoming** (Start preparing), **preparing** (Mark as done, animating subtle blue gradient), **done** (green time badge, no actions). **Edit mode**: change quantities, Add items, Save/Cancel. Figma DS nodes 852-162, 852-69, 852-71, 852-120.

## Overview

- **States**: `incoming` → "Start preparing" + edit + delete. `preparing` → animated blue gradient background, "Mark as done" + edit + delete. `done` → green time badge, no actions.
- **Edit mode**: Set `isEditing` true to show OrderList with Counter per item, "Add" button, Save and Cancel. Consumer handles Add (dropdown on desktop, bottom panel on mobile).
- **Time badge**: Top-right; default (white/gray) or green when `state === 'done'`.

## When to use

- Bar/kitchen order queue: see incoming orders, mark preparing, mark done.
- Edit orders (quantities, add items) with Save/Cancel.

- Use semantic structure (article, header, footer).
