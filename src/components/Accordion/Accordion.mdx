# Accordion

Accordion with collapsible items. Each item has a **trigger** (title + chevron) and a **panel** (content). Chevron points down when collapsed, up when expanded.

Use the **Controls** panel to try allowMultiple and defaultExpandedIds.

## Usage

- **items**: Array of `{ id, title, content }`.
- **allowMultiple**: When false (default), at most one item is open; when true, multiple can be open.
- **defaultExpandedIds**: Initial expanded ids (uncontrolled).
- **expandedIds** / **onExpandedChange**: Controlled mode.

### Single open across multiple accordions (AccordionGroup)

When you have several Accordions on a screen and want only one item open at a time across all of them, wrap them in **AccordionGroup**. Item ids must be unique across all accordions in the group.

```tsx
import { AccordionGroup, Accordion } from '@your-design-system';

<AccordionGroup>
  <Accordion items={faq1} aria-label="FAQ section 1" />
  <Accordion items={faq2} aria-label="FAQ section 2" />
</AccordionGroup>
```

## Accessibility

- Trigger is a `<button>` with `aria-expanded` and `aria-controls`.
- Panel has `id`, `role="region"`, `aria-labelledby`, and `hidden` when collapsed.
- Enter/Space on trigger toggles the panel.
- Focus outline on trigger (`:focus-visible`).
