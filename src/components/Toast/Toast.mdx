# Toast

Fixed bottom-right notification. Four variants (error, success, warning, info) with icon, message, and a bottom progress bar that fills as the auto-dismiss countdown runs. Timer and progress pause on hover.

## Usage

- **Message**: Required text shown in the toast.
- **Variant**: `error` | `success` | `warning` | `info` — controls icon and semantic colors (border, background, icon, progress).
- **durationMs**: Auto-dismiss delay in milliseconds (default 5000). Progress bar width reflects remaining time.
- **onDismiss**: Callback when the toast is dismissed (after duration or when the consumer removes it).

Consumers typically control visibility with state: render the toast when a condition is true and call `onDismiss` to clear it (e.g. set state to hide).

## Variants

| Variant   | Use case                          |
| --------- | --------------------------------- |
| `error`   | Errors, failed actions            |
| `success` | Success feedback (e.g. "Saved")  |
| `warning` | Warnings, caution                 |
| `info`    | Informational messages            |

## Accessibility

- `role="alert"` and `aria-live="assertive"` so screen readers announce the toast.
- Progress bar has `aria-hidden` (decorative).
