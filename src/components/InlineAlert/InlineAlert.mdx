# InlineAlert

Inline status alert: full width, left inner bar (0.625rem), icon, title, optional description, optional action button. Figma DS nodes 253-701, 266-2245, 266-2258, 266-2271, 278-6631, 278-6638, 278-6645, 278-6652.

## Overview

- **Full width**: `width: 100%`.
- **Left inner bar**: 10px (0.625rem) via inset box-shadow; padding-left clears it.
- **Desktop**: Horizontal: icon | content (title + description) | action (optional, right).
- **Mobile (&lt;768px)**: Stacked: icon → text → button.
- **Variants**: info, error, success, warning (border, left bar, icon bg, title color).
- **Action**: Optional `action` prop (e.g. button "Los op") inside the alert.
- **Sizes**: default (radius 12px), compact (pill).

## When to use

- Inline feedback (info, success, error, warning) next to content or in forms.
- When you need a compact alert without a modal or toast.

## States / eight designs

Four variants × with or without action = eight designs. Explore via **Controls**: `variant`, `title`, `description`, `showAction`, `actionLabel`, `size`.
