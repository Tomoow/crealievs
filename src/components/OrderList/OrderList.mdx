# OrderList

Order list with **OrderListItem** (image, title, price • points, Counter) and **OrderListSummary** (label, total • points, item count). Figma DS nodes 856-701, 847-5136, 847-4512, 856-743.

## Overview

- **OrderList**: Container `<ul>` with `role="list"`; children are list items.
- **OrderListItem**: Row with product image (40×40), title (semi-bold), price (brand) • points (subtle), and **Counter** on the right.
- **OrderListSummary**: Two lines on the left (label + total • points), item count on the right; flex `space-between`, aligned to bottom.

## When to use

- Cart or order review: list of items with quantity and a total summary.
- Any list where each row has image, text, and a quantity control.

## Example

<Canvas of={OrderListStoriesNamed.Default} />

Use the **Controls** panel to change item count, summary visibility, and summary text. Counter is interactive in the story.

## Accessibility

- **OrderList**: `role="list"` for list semantics.
- **OrderListItem**: Each row is a list item; Counter has `aria-label` including product name.
- **OrderListSummary**: Wrapper has `role="group"` and `aria-label={label}`.
